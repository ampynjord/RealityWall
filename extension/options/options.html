RealityWall

RealityWall appelle directement l'API Anthropic avec votre propre clé : elle est stockée uniquement sur cet appareil et n'est jamais envoyée ailleurs qu'à api.anthropic.com.

Analyse

Sans recherche web, l'analyse est nettement plus rapide mais ne fournit aucune source.

Joint les images du message, une capture de la vidéo et ses sous-titres quand ils existent. Le son n'est pas analysé.

Comment obtenir une clé API

  1. Créez un compte sur platform.claude.com, la console Anthropic.
  2. Générez une clé API dans les réglages de votre compte.
  3. Collez-la ci-dessus et enregistrez.

Utilisation

  • Sélectionnez un texte (un commentaire, un passage) puis cliquez sur le bouton « Analyser » qui apparaît, ou faites un clic droit → « Débunker avec RealityWall ».
  • Sans sélection : cliquez sur l'icône de l'extension (ou clic droit → « toute la page ») pour analyser la publication entière.
  • Clic droit sur une image ou une vidéo → « Débunker ce média ».
  • Raccourci clavier : Alt + Maj + R (modifiable dans les raccourcis de votre navigateur).
  • Sur mobile (Firefox Android) : sélectionnez un texte puis touchez l'icône de l'extension.
